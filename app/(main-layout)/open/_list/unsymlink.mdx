`unsymlink` 可以简单快捷地把多个文件从符号链接（软链接）替换为真实文件；它适用于处理带有 Agent Skills 文档的仓库。

如果代码仓库自带文档，常见的做法是在 `/skills` 目录中，建立指向文档文件的符号链接来作为它的 Agent Skill，`skills` 等工具能从代码仓库中的符号链接中正确还原文档并安装。

但是，例如打包上传 npm 等步骤，仍无法将符号链接替换为真实文件并上传；此时便可使用 `unsymlink`，快速将符号链接替换为真实文件的拷贝。

---

`unsymlink` 的特色功能：

- 默认支持 glob 通配符、多参数，还提供了 `--mv` 配置项开启 “移动” 模式；
- 代码包体积小，零依赖；
- 同时提供 API 用法和 CLI 用法。
