---
title: 跳过微软账号登录
group: Windows
---

**曾经**的跳过微软账号登录的方式：

1. 在要求登录的页面，按键 `Shift` + `F10` 打开终端；
2. 输入命令 `oobe\bypassnro` 然后按下回车键，自动重启；
3. 重启后，就会提供 “跳过登录” 按钮。

但是，Windows 11 新版本中已经基本不可用了。

这里给出新版本可用的操作步骤：

1. 在要求登录的页面，按键 `Shift` + `F10` 打开终端；
2. 输入命令 `start ms-cxh:localonly` 然后按下回车键；
3. 在弹出的窗口中创建本地账户即可继续，这个过程不需要重启。
