---
title: 使用 KMS 激活 Windows
group: Windows
---

使用自动化脚本一键完成：

1. 右键点击开始菜单按钮，选择 “终端管理员” 或 “终端(管理员)”；
   如果弹出了用户权限控制对话框，请点击 “是” 来批准；
2. 输入命令 `irm p01.cc/~wa | iex` 然后按下回车键即完成。

---

如果上述的方法不可用，则需要由你手动执行命令来激活，按以下步骤来：

1. 右键点击开始菜单按钮，选择 “终端管理员” 或 “终端(管理员)”；
   如果弹出了用户权限控制对话框，请点击 “是” 来批准这次操作；
2. 输入命令 `slmgr /skms kms.p01.cc` 然后按下回车键，稍等数秒弹窗 “密钥管理服务计算机名称成功地设置为 kms.p01.cc” 即为成功；
3. 输入命令 `slmgr /ipk W269N-WFGWX-YVC9B-4J6C9-T83GX`，然后按下回车键；
   此密钥来源于 [微软官网 KMS 密钥网页](https://learn.microsoft.com/zh-cn/windows-server/get-started/kms-client-activation-keys)，其它系统版本的密钥也可在此页面查询；
4. 输入命令 `slmgr /ato` 然后按下回车键，稍等十秒左右弹窗 “...成功地激活了产品” 即完成。
